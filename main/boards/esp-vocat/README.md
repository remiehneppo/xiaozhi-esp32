# ESP-VoCat NekoBuddy

## Giới thiệu

<div align="center">
    <a href="https://oshwhub.com/esp-college/echoear"><b> Nền tảng nguồn mở Lichuang </b></a>

ESP-VoCat NekoBuddy là một bộ kit phát triển AI thông minh, được trang bị mô-đun ESP32-S3-WROOM-1, màn hình cảm ứng tròn QSPI 1.85 inch, mảng micro kép, hỗ trợ nhận dạng giọng nói ngoại tuyến và thuật toán định vị nguồn âm. Chi tiết phần cứng có thể xem tại [Dự án nguồn mở Lichuang](https://oshwhub.com/esp-college/echoear).
